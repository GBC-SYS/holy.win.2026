# 01. Style Reference — 맨 위 세 줄

모든 DESIGN.md의 첫머리에 들어가는 부분. AI가 "이 앱이 어떤 느낌이어야 하는지"를 판단하는 기준이 됨.

## 채우는 칸

```
# 홀리윈 2026 전도 대상자 — Style Reference
> 전도 대상자 이름을 올리고 함께 기도하는 모바일 전도 대상자. 따뜻한, 정성스러운, 인상적인.

**Theme:** light
**Platform:** mobile 390 × 844
```

**코드 현황:** 앱 전체는 따뜻한 톤의 밝은 배경(`--bg`) 위에 올라간 단일 라이트 테마다. 티켓·최신 제출 카드는 순백(`--paper`)으로 한 단계 더 밝게 떠 보이고, 이전 명단 같은 절제된 카드는 배경보다 살짝 가라앉은 `--card-muted`로 구분한다(자세한 관계는 02번 참고). dark 테마는 별도로 존재하지 않는다.

## 작성 규칙

- **분위기 단어는 정확히 3개.** 2개는 좁고, 4개 이상이면 서로 충돌해 AI가 어느 쪽을 따를지 못 정함
  - 나쁜 예: 고급스러운 / 친근한 / 미니멀한 / 대담한 (4개, 서로 충돌)
  - 좋은 예: 절제된 / 또렷한 / 신뢰감 있는 (3개, 방향이 하나)
- **세 단어가 같은 방향을 가리켜야 한다.** 하나가 "절제", 하나가 "대담"이면 뒤의 색·굵기·여백을 정할 때마다 기준이 흔들림
- **화면 크기를 반드시 명시.** 안 적으면 데스크톱 기준으로 만들고 모바일이라 우기는 경우가 잦음
- **테마는 하나만.** light/dark를 동시에 만들어달라고 하면 색 규칙이 두 배로 필요해짐 — 별도 파일로 분리 권장

## 분위기 단어 참고 어휘

고를 때 참고만 할 것. 그대로 복사하지 말고 실제 서비스의 성격에 맞게 바꿔 쓴다.

| 유형 | 참고 단어 조합 |
|---|---|
| B2B SaaS / 업무 도구 | 또렷한, 신뢰감 있는, 군더더기 없는 |
| B2C 커머스 / 쇼핑몰 | 활기찬, 따뜻한, 편안한 |
| 콘텐츠 / 미디어 | 차분한, 읽기 편한, 정제된 |
| 랜딩페이지 / 마케팅 | 확신 있는, 임팩트 있는, 명료한 |
| 크리에이티브 / 브랜드 | 개성 있는, 감각적인, 대담한 |

## 이 세 단어가 뒤의 파일에 미치는 영향

여기서 고른 단어가 02~08의 값을 정하는 기준이 됨. 값이 고민될 때 이 표로 되돌아온다.

| 분위기 | 색(02) | 글자(03) | 여백(04) | 모서리(05) | 깊이(06) |
|---|---|---|---|---|---|
| 절제된 / 정제된 | 채도 낮게, 무채색 중심 | 굵기 차를 작게 | 넉넉하게 | 작게 또는 0 | 그림자 없이 |
| 활기찬 / 대담한 | 채도 높은 포인트 색 | 제목 굵기를 크게 | 촘촘해도 됨 | 크게 | 그림자 허용 |
| 신뢰감 있는 | 대비를 확실하게 | 크기 위계를 또렷하게 | 규칙적으로 | 작게 | 테두리 중심 |
| 따뜻한 / 편안한 | 난색 계열, 대비 완화 | 행간을 넉넉하게 | 넉넉하게 | 크게 | 옅은 그림자 |

## 체크리스트
- [ ] 분위기 단어가 정확히 3개인가
- [ ] 세 단어가 서로 충돌하지 않고 한 방향을 가리키는가
- [ ] 테마(light/dark)를 하나만 정했는가
- [ ] 화면 크기를 숫자로 적었는가
