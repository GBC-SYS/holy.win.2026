라벨, 다이얼로그 제목/설명, 에러 메시지 등 UI 표면에 노출되는 모든 곳에서 "PIN"이 아니라 "비밀번호"라는 단어만 쓴다. 단, DB 컬럼명(`pin_hash`), RPC 파라미터명(`pin`), 내부 변수/함수명 등 코드 식별자는 영문 `pin`을 그대로 유지한다 — 사용자가 지적한 범위는 "사용자가 보는 텍스트"였고 코드 식별자까지 바꾸라는 요청은 아니었음.

**Why:** [[project-pin-ownership-and-next-steps]] 기능을 구현하던 중 사용자가 "PIN이라는 단어를 쓰지 말고 모든 곳에서 비밀번호로 표기해달라"고 명시적으로 교정함(2026-09-30). 한국어 서비스에서 "PIN"보다 "비밀번호"가 사용자에게 더 익숙한 용어라는 취지로 보임.

**How to apply:** 이 프로젝트에서 향후 비밀번호/인증 관련 UI 텍스트를 새로 쓰거나 수정할 때, "PIN"이라는 단어가 사용자 노출 텍스트에 섞여 들어가지 않도록 매번 확인할 것.
